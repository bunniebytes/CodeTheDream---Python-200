### Scenario A – Lightweight Compute

The first scenario used a small virtual machine intended for light workloads:

    VM Type: Standard_B1s
    Specifications: 1 vCPU, 1 GB RAM
    Usage: 8 hours per day, 5 days per week (~160 hours/month)

##### Estimated Costs

    Monthly Cost: $1.66
    Yearly Cost: $19.97

This scenario demonstrated how inexpensive cloud computing can be for lightweight or short-duration workloads. The Azure Pricing Calculator estimate was very close to the scripted estimate, with only a small discrepancy caused by rounding of the hourly rate.

### Scenario B – Heavy Analytics Workload

The second scenario simulated a large-scale analytics environment with GPU acceleration, a managed SQL database, and cloud storage.

#### Components

    1. GPU Virtual Machine
    	Standard_NC6s_v3
    	6 vCPUs and 1 NVIDIA V100 GPU
    	Running continuously (730 hours/month)
    2. Azure SQL Database
    	General Purpose tier
    	4 vCores
    3. Azure Blob Storage
    	1 TB of stored data

#### Estimated Costs

    **GPU VM**
    	Monthly: $2,233.80
    	Yearly: $26,805.60
    **Azure SQL Database**
    	Monthly: $741.16
    	Yearly: $8,893.90
    **Azure Blob Storage**
    	Monthly: $22.34
    	Yearly: $268.12
    **Total Estimated Cost**
    	Monthly Total: $2,997.30
    	Yearly Total: $35,967.62

One of the most interesting findings was how dramatically costs increased when GPU-enabled hardware and continuously running services were added. While the lightweight VM cost less than $2 per month, the analytics environment approached $3,000 per month due primarily to the GPU VM and SQL Database costs.

Another surprising detail was how affordable Azure Blob Storage was compared to compute resources. Even storing 1 TB of data only added about $22 per month, showing that storage is relatively inexpensive compared to high-performance computing.

I also noticed that the estimates generated by the script closely matched the Azure Pricing Calculator results. Minor differences were likely caused by rounding of hourly rates in the calculator interface.

Overall, this project demonstrated how important it is to carefully plan cloud infrastructure usage, since compute resources, especially GPU workloads, can become very expensive when running continuously.

### Write-Up

_What each scenario costs, and whether the numbers surprised you._

Scenario A, the lightweight compute setup using a Standard_B1s VM for about 160 hours per month, was relatively inexpensive at $1.60 per month depending on the operating system and region selected. Scenario B, the heavy analytics workload, was much more expensive because it included a GPU-enabled Standard_NC6s_v3 VM running continuously, an Azure SQL Database with 4 vCores, and 1 TB of Blob Storage. The total estimate for Scenario B was $2233.80. I expected the GPU VM to be expensive, but I was still surprised by how quickly costs increased when combining GPU compute, databases, and storage together.

_Anything interesting you found while exploring the Pricing Calculator beyond the two required scenarios._

While exploring the Azure Pricing Calculator, I found it interesting how many pricing options affect the total cost, including VM operating systems, reserved instances, redundancy settings for storage, and database performance tiers. I also noticed that storage itself is relatively cheap compared to compute resources, especially GPU-based virtual machines.

_What the script printed, and whether the calculated costs matched what you saw in the Pricing Calculator. (They should -- if they don't, note the discrepancy.)_

The script printed the estimated monthly costs for both scenarios, and the values closely matched what was shown in the Azure Pricing Calculator.

The lightweight VM scenario produced a low monthly estimate of $1.66 in the calculator versus $1.60 from the script’s estimate. The GPU analytics scenario resulted in a much higher monthly estimate of $2233.80 due to the continuous runtime and specialized hardware requirements.

There were no major discrepancies between the script calculations and the Azure Pricing Calculator estimates. The small $0.06 discrepancy in the lightweight VM scenario is likely due to rounding differences when determining the estimated hourly cost. For example, the hourly rate may have been rounded to $0.01 even though the actual value could be slightly higher.
